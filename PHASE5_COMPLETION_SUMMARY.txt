WHAT REQUIRES EXTERNAL SETUP (Before Launch)
================================================================================

Before deploying to production, set up:

1. Sentry Account (for error tracking)
   - Free tier available at sentry.io
   - Integration template ready in Phase 5
   - Set SENTRY_DSN environment variable

2. Better Stack Account (for log aggregation)
   - Free tier available at betterstack.com
   - LogShipperService ready to use
   - Set LOG_SHIPPER_SOURCE_TOKEN environment variable

3. Uptime Monitoring Service
   - Recommended: UptimeRobot (free tier available)
   - Alternative: Pingdom, Datadog, self-hosted Prometheus
   - Health endpoint ready at /api/health

4. Production Database
   - PostgreSQL 14+ required
   - RLS policies enabled
   - Regular backups configured

5. Domain and TLS Certificate
   - Domain DNS configured
   - TLS certificate installed
   - HTTPS enforced
