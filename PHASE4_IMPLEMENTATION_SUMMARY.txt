DEPLOYMENT ORDER (CRITICAL SEQUENCE)
================================================================================

1. Database Backup
   Command: Automated by release.sh
   File: backups/hrms_backup_YYYYMMDD_HHMMSS.sql

2. Run Migrations
   Command: npx prisma migrate deploy
   Location: api/ directory
   Timeout: Depends on schema changes

3. Validate Migrations
   Command: npx prisma migrate status
   Result: Confirm no pending migrations

4. Start API Servers
   Command: docker-compose up api
   MUST run after migration validation

5. Health Checks
   Command: curl http://api:3000/health
   Result: Confirm API is responding
